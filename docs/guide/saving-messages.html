Saving Messages

Export what matters to disk — and browse it later, even offline.

Saving from the grid

Right-click a message in the grid to open the context menu:

  • Save Selected — saves the currently selected message.
  • Save All — saves every loaded (filtered) message in the grid.

Both offer two formats:

FormatExtensionContents
As RAW .klm The full serialized record — key, value, headers, and metadata — in KafkaLens's binary format. This is what the offline Saved Messages browser reads.
As Formatted .txt A human-readable text file: key, timestamp, partition, offset, headers, and the pretty-printed value.

Save All respects the current filter — with a filter active, only the visible messages are exported.

Where files land

Messages are written under the Saved Messages folder (default: %LocalAppData%\KafkaLens\SavedMessages on Windows — change it in Preferences → Browser), organized as: 

<SavedMessages>/<Cluster>/<Topic>/<Partition>/<offset>.klm
<SavedMessages>/<Cluster>/<Topic>/<Partition>/<offset>.txt

After saving, a notification bar appears below the menu: it reports the count and location, and offers Open folder, Hide for this session, and Never show again (re-enable in Preferences).

Browsing saved messages offline

Cluster → Open Saved Messages (Ctrl+O) opens a folder of .klm files as if it were a cluster: the folder structure becomes the topic/partition tree, and you can browse, filter, and inspect messages exactly like a live cluster — no Kafka connection required.

  • Point it at your Saved Messages root to browse everything you've saved, or at a specific cluster/topic subfolder to narrow the view.
  • Saved-messages tabs restore on startup like normal cluster tabs when Restore open tabs is enabled.
  • You can't re-save from a saved-messages tab — the Save menu items are only available on live clusters.

Sharing a saved-messages folder is an easy way to hand a teammate a slice of a topic for offline analysis.
