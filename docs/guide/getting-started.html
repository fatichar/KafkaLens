Getting Started

From download to your first messages in a few minutes.

1. Install KafkaLens

Grab the latest build from the download page or directly from GitHub Releases. All packages are self-contained — you do not need a .NET runtime installed.

Windows

  1. Download KafkaLens-<version>-win-x64.exe.
  2. Run the installer and follow the wizard.
  3. Launch KafkaLens from the Start Menu.

If Windows SmartScreen warns about an unrecognized app, choose More info → Run anyway.

macOS (Apple Silicon)

  1. Download KafkaLens-<version>-macos-arm64.zip.
  2. Extract the archive and move the app to a folder of your choice (e.g. Applications).
  3. Launch the KafkaLens binary.

macOS Gatekeeper may block an unsigned binary. If that happens, either right-click → Open, or clear the quarantine attribute: 

xattr -dr com.apple.quarantine /path/to/KafkaLens

Linux

  1. Download KafkaLens-<version>-linux-x64.zip.
  2. Extract it: unzip KafkaLens-*.zip -d kafkalens
  3. Make the binary executable and run it:
chmod +x kafkalens/KafkaLens
./kafkalens/KafkaLens

A desktop environment with X11 or Wayland is required.

2. Add your first cluster

  1. Open Cluster → Edit Clusters (or press Ctrl+E).
  2. In the Direct Clusters tab, click Add.
  3. Enter a friendly name (e.g. Local dev) and your bootstrap servers (e.g. localhost:9092 or a comma-separated list such as kafka1:9092,kafka2:9092).
  4. Click OK, then Save in the dialog.
📷 Screenshot needed The "Edit Clusters & Clients" dialog with the Direct Clusters tab open and one cluster added.

Direct connections use plaintext. If your cluster requires SASL/TLS, place it behind the KafkaLens gRPC backend or connect over a private network/VPN. See Connecting to Kafka.

3. Open the cluster

Go to Cluster → Open Cluster and pick the cluster you just added. A new tab opens showing the cluster's topics. The colored dot next to the cluster name shows its connection status — see connection status for what each color means.

📷 Screenshot needed An open cluster tab: topic tree on the left, message browser in the center, fetch panel on the right.

4. Fetch your first messages

  1. In the Topics tree on the left, select a topic (or expand it and pick a partition).
  2. In the Fetch panel on the right, keep the defaults (From: End, a small Count).
  3. Click Fetch Messages.

Messages stream into the grid as they arrive. Click any row to inspect it in the viewer below — key, value, timestamp, headers — all covered in Inspecting Messages.
