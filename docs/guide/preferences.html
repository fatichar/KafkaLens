Preferences & Settings

Every option in the Preferences window, and where the files live.

Open Preferences from Edit → Preferences. Changes apply when you click Save; Cancel discards them. The window has four tabs.

Message Format

A matrix of all available formatters — built-in and plugin-provided — with a Keys and Values checkbox per formatter. Unchecking hides that formatter from the corresponding dropdowns (topic configuration and the viewer's Format combo), which keeps long formatter lists manageable.

Where settings are stored

KafkaLens keeps its data in a per-user directory:

OSPath
Windows%LocalAppData%\KafkaLens
Linux~/.local/share/KafkaLens
macOS~/Library/Application Support/KafkaLens
File / folderContents
cluster_info.jsonDirect cluster definitions.
client_info.jsonKafkaLens client (remote backend) definitions.
settings.jsonPreferences: theme, Kafka config, browser config, open tabs.
topic_settings.jsonPer-cluster/topic key and value formatter choices.
plugins/Installed plugins and their state.
logs/KafkaLens.logDiagnostic log file (see Troubleshooting).
SavedMessages/Default saved-messages root (configurable).

The fastest way there: Cluster → Edit Clusters → Open Settings dir….

Themes

View → Theme switches between Light, Dark, and System (follows your OS light/dark setting, live). Plugin-provided themes appear in the same submenu. The choice persists across restarts.
