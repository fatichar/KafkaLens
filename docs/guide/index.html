Welcome to KafkaLens

KafkaLens is a cross-platform desktop client for Apache Kafka, available for Windows, macOS, and Linux. It lets you connect to your clusters, browse topics and partitions, fetch and inspect messages, filter them with a powerful boolean syntax, and save what matters to disk.

New to KafkaLens? Start with Getting Started and you'll be browsing messages in a couple of minutes.
