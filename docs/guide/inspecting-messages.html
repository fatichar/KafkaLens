Inspecting Messages

The viewer, formatters, and everything in the message detail pane.

The message viewer

Select any row in the message grid and the lower pane shows its contents in two tabs:

  • Body — the message value, rendered by its formatter (pretty-printed JSON, decoded text, numbers, and so on).
  • Headers — a table of the Kafka record headers (Name / Value), when the message carries any.

The display toolbar

Below the viewer, the toolbar has three controls:

ControlWhat it does
Filter Narrows the displayed message to lines or JSON properties containing the text you type — handy for huge payloads.
Use Object Filter For JSON payloads: when checked, the filter keeps whole JSON properties whose key or value matches; when unchecked, it keeps matching text lines.
Format Overrides the formatter for the selected message only — the topic's configured formatter is unchanged.
Zoom Slider that scales the viewer font between 6 and 32 pt.

Object filter vs. line filter (JSON)

With Use Object Filter on, typing userId in a JSON message prunes the document to the properties whose key or value contains userId — nested objects and array elements are filtered recursively, so you see the matching branches in context. With it off, only the lines that literally contain the term survive.

Formatters

Formatters decode raw message bytes into something readable. KafkaLens applies one formatter to the key and one to the value of every message in a topic.

Built-in formatters

FormatterOutput
JsonParses and pretty-prints JSON payloads. Default formatter.
TextRaw UTF-8 text.
Int8 / Int16 / Int32 / Int64Signed integers decoded from binary.
UInt8 / UInt16 / UInt32 / UInt64Unsigned integers decoded from binary.

Additional formatters can come from plugins — they appear in the same dropdowns. Formatters can be enabled or disabled separately for keys and values in Preferences → Message Format.

Automatic detection

The first time you fetch from a topic, KafkaLens inspects the incoming data and guesses the key and value formatters. The choice is saved automatically per cluster and topic, so next time it's already right.

Changing a topic's formatters

Open the Configuration tab in the browser (with the topic selected) to set Key Formatter and Value Formatter explicitly:

  • Guess — re-run auto-detection for key or value.
  • Apply to every cluster — use the same formatter for a topic of this name on all clusters (useful for dev/staging/prod twins).
  • Save — persists the choice to topic_settings.json in the settings directory.
📷 Screenshot needed Configuration tab showing Key Formatter and Value Formatter dropdowns with Guess buttons.

The Format dropdown in the display toolbar changes only the message you're looking at — it doesn't touch the topic's saved setting.

Copying message data

Right-click a message in the grid and use Copy to grab the Key, Value, Offset, Timestamp, or All of it to the clipboard.
